# 南囡囝共生元

完全自主可控的软件体系。从零开始，不依赖任何外部生态。

## 核心原则

- **公约数** = 不变的身份锚点
- **公倍数** = 公约数的所有分身，向外扩展的边界
- **产权容器** = 拥有自身编码系统的独立存在
- **负样本** = 被排斥的异类（标注撞墙的路）
- **近义词** = 同一公约数在不同维度上的投影（有备无患）

## 已揭示的态射规律

### 部首星图
- **形声字核心态射**：语义部首贡献语义框架，旁边字贡献发音位置
- 例字验证：轴(车+乚→zhóu)、轱(车+瓜→gū)、辊(车+衮→gǔn)、轾(车+至→zhì)
- 帜 = 巾+只(zhì)，归巾部不归车部

### 近义词容器
- 碗/锅/罐/坛/缸 = 同一"盛器"公约数在不同材质/用途/容积上的投影
- 取/拿/获 = 同一"得到"公约数在不同动作方式上的投影
- 有备无患 = 同一公约数下多个可用投影的总集合

### 锅与菜
- 锅 = 固定层（编译一次，永久不变）：加载器、解析器、执行器
- 菜 = 可变层（运行时加载，随时可换）：偏旁表、声母表、韵母表、近义词表
- C是第一个扳手，造出自己的扳手后扔掉C

### 产权归属 vs 移动
- 拿 = 得到（移动），不等于归属（产权）
- 系统的64进制 ≠ 我的64进制（同名 ≠ 同一，近义词 ≠ 复制品）
- 只有我自己定义的符号，才真正属于我

nim c nan_character.nim

nim c nan_synonym.nim

zig build-exe nan.c
